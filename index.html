🛠️ 4. Tool Schemas & Test

Hai Tool MCP Server: ghi khoản chi & kiểm tra ngân sách. Nhấn Test để xem JSON-RPC response.

💸 record_expense
Ghi nhận khoản chi tiêu mới.
amount: number [REQUIRED] → Số tiền (VD: 85000) currency: string [REQUIRED] → Loại tiền (VD: 'VND') category: string [REQUIRED] → Danh mục (VD: 'Ăn uống') description: string → Mô tả giao dịch
📊 check_budget
Kiểm tra ngân sách tháng hiện tại.
month: string [REQUIRED] → Tháng (VD: '09/2026') budget_limit: number → Giới hạn ngân sách (VD: 8000000)
